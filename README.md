# Exp_Adap_AI: 경험 기반 적응 모델 연구

사람이 경험을 통해 의사결정 방식을 바꿔 가는 과정(적응)을 모델링하고, 사전학습된 신경망이 자연어로 해석 가능한 범위에서 사람처럼 적응하게 만드는 것을 목표로 하는 개인 연구 프로젝트입니다.

이 저장소는 연구 맥락의 **단일 저장소**입니다. Claude, Codex, 그리고 나중의 나 모두 여기서 출발합니다. 데이터는 커밋하지 않습니다(`.gitignore`).

## 처음 읽을 순서

1. [docs/context/01_목표와_현재방향.md](docs/context/01_목표와_현재방향.md): 연구 목표, 지금 어디에 있는지, 열린 질문
2. [docs/context/02_결정_기록.md](docs/context/02_결정_기록.md): 날짜별 결정과 근거
3. [docs/context/03_가설과_질문_일지.md](docs/context/03_가설과_질문_일지.md): 진행 중인 가설과 의문
4. [docs/context/04_결과_요약.md](docs/context/04_결과_요약.md): 체스 데이터 분석 결과
5. [docs/context/05_선행연구.md](docs/context/05_선행연구.md): 검토한 논문과 연결점
6. [docs/context/06_작업_규칙.md](docs/context/06_작업_규칙.md): 협업 방식, Codex 지시문 형식, 보안·데이터 규칙
7. [docs/context/07_문서_링크.md](docs/context/07_문서_링크.md): Claude 문서·아티팩트 링크 모음

## 폴더 구조

| 폴더 | 내용 |
|---|---|
| `docs/context/` | 연구 맥락 문서 (위 목록) |
| `docs/plan/` | 연구 계획서. 현재 기준은 v3, v2는 보관용 |
| `docs/codex/` | Codex에 맡긴 작업 지시문과 기준 코드 |
| `docs/advice/` | 조언 메모 |
| `analysis/` | 체스 분석 스크립트, 요약 JSON, 그림. 원자료 CSV와 이용자 이름 목록은 제외 |
| `experiments/` | 시뮬레이션 실험 (가짜 사람 데이터로 갱신 규칙 복원) |
| `data/`, `outputs/` | 로컬 전용. 커밋하지 않음 |

## 맥락을 갱신하는 규칙

- 결정이 생기면 `02_결정_기록.md`에 한 줄 추가합니다(날짜, 결정, 근거, 관련 문서).
- 새 의문이나 가설은 `03_가설과_질문_일지.md`에 적고, 풀리면 결론과 바뀐 것을 덧붙입니다.
- 분석 결과는 `04_결과_요약.md`에 요약하고, 스크립트는 `analysis/` 아래에 둡니다.
