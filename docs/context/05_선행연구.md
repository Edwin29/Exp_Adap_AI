### Hattori 모델 세부 사항 (방법 절)
- 단순 순환망(tanh), 행위자 50 + 평가자 50 유닛. 입력은 직전 보상, 왼쪽, 오른쪽 세 개
- A2C, RMSProp + 시간 역전파. 학습률 0.0005, 할인율 0.5, 엔트로피 가중치 0.5, 가치 손실 가중치 0.01, 펼침 길이 50
- 한 세션 500시행 동안 가중치 고정 → 세션 끝에 갱신 → 300세션. 매개변수 약 5천 개라 CPU로 재현 가능(추정)
- 과제: 보상 확률 0.6 대 0.1(또는 0.525 대 0.175), 60~80시행마다 신호 없이 반전, 걸린 보상은 가져갈 때까지 남음
- 이 논문의 "느린 가중치 갱신"은 우리 말로 하면 사전학습에 해당한다
