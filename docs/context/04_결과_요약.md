# 결과 요약 (체스, Lichess 2018)

스크립트는 `analysis/` 아래, 원자료와 중간 산출물은 PC의 `data/`에 있다(커밋하지 않음). 상세 문서 링크는 [07_문서_링크.md](07_문서_링크.md).

공통 측정 방법: Stockfish 16, 깊이 10, Threads=1, Hash=64. Lichess 승률·정확도 공식을 쓰고, 승률 손실 30 이상을 큰 실수로 본다. 남은 시간 10초 미만인 수는 뺀다.

## 1. 2018-01 전체 헤더 분석 (2026-10-21) — `analysis/2018-01/`
- 1,794만 판, 32.7만 명. `%clk` 99.5%, `%eval` 8.3%(후보 수는 엔진이 필요)
- 블리츠+불릿이 77%. 다작자는 한 시간 제한에 98% 집중
- 한 달 500판 이상 블리츠 5,258명은 숙련자(레이팅 변화 중앙값 +11). 1500 신규로 100판 이상 둔 블리츠 4,691명(첫 약 30판은 레이팅 보정)
- 2018년의 "Standard"는 지금의 래피드

## 2. 왕 안전과 "신규" 집단 (2026-10-22) — `analysis/2018-01/user_change/`, `king_safety/`, `analysis/2018-02/`
- 지표: 캐슬링 가능할 때 미룸(상대 퀸이 있을 때만). 방패 폰 약화는 타당도 실패로 탈락
- 개인 변화: |z|>2가 11.1%, 무작위 기준 5.1%. 양방향이라 집단 평균은 평평함
- 레이팅 수준의 전형적인 값으로 끌려가는 경향이 무작위보다 조금 큼. 1월 변화는 2월에 이어지지 않고 일부 되돌아감
- 왕 공격 패배 직후 효과 0 (사전 추세 보정 뒤 −0.08pp ± 0.52)
- 엔진 확인: 1500 시작 "신규" 100명은 레이팅 +62점이지만 정확도 86.6 → 86.6. 레이팅 상승은 보정일 뿐, 대부분 초보가 아님

## 3. 진짜 초보 (2026-10-22) — `analysis/beginners/`
- 대상: 새 계정이면서 30판 안에 레이팅이 1200 아래로 떨어진 984명
- 정확도 83.4 → 83.8 → 84.3, 큰 실수 4.0 → 3.6%
- 줄어든 큰 실수의 약 70%는 한 수짜리 공짜 기물 실수(지각). 시간 압박 가설 탈락. 전술·메이트는 변화 없음
- 캐슬링 습관은 제각각 흔들리고 사건 반응 0
- 지각 사건 연구: 기물을 내주고 진 직후 효과 없음(−0.055, 무작위 SD 0.043), 예상 밖 패배도 차이 없음

## 4. 3~12월 추적 (2026-10-23) — `analysis/beginners/mar_dec/`, `unobserved/`
- Codex가 984명의 3~12월 경기를 내려받고 엔진 평가(A군 150명은 전체 경기, B군 834명은 달마다 첫 20판)
- 정확도 84.35(1월 초) → 85.0(3월) → 85.5(6월) → 85.6(12월). 지각 실수 −31%, 가치 실수 −12%. 빨리 늘고 약 6월부터 멈춤
- 다작자(400판 이상, 71명): 향상 23%, 하락 6%, 변화 없음 72%
- 3월 → 11~12월 향상은 그 사이 둔 판 수와 무관. 가장 좋은 예측 변수는 3월 수준(r −0.64)
- 활동 비율 77%(3월) → 43%(12월)
- 판 수 대 경과 시간: 800판 시점에서 걸린 날짜가 2배면 정확도 +0.50 ± 0.22. 피로 때문은 아님
- 블리츠 외 경기는 전체의 32%(사람 중앙값 17%). 이를 넣어도 경과 일수 효과가 +0.25~0.33으로 남음
- 사람 안 간격 효과(상승 구간): +0.10 ± 0.08, 유의하지 않음

## 5. 예측 기준선 (2026-10-23) — `analysis/beginners/prediction/pred.py`
- 1월 자료로 3~12월 월별 정확도를 예측. 사람 단위 5겹 교차검증
- 정확도 RMSE: 변화 없음 1.66 → 경과 일수 + 전체 판 수 1.39. 잡음 바닥 0.63
- 지각 실수(100수당): 0.57 → 0.42. 바닥 0.23
- 남은 오차의 약 97%가 사람별로 지속되는 차이
- 2~3월 기록으로 사람별 수준을 갱신하면 4~12월 정확도 RMSE 1.43 → 1.11. **이것이 U가 넘어야 할 기준**

## 6. 개인차 (2026-10-24) — `analysis/beginners/prediction/a1.py`~`a3.py`
- 경험 종류별 무게(경과 일수 2배당 정확도): 래피드·클래식 +0.09, 변형 +0.05, 불릿 약 0. 다른 경기를 많이 둔 사람의 치우침이 +0.70 → +0.36으로 줄어듦
- 같은 사람 안에서 어떤 달에 더 많이 두면: 정확도 +0.04 ± 0.05, 지각 실수 −0.036 ± 0.020. 사람 사이 효과(−0.12 ± 0.03)의 약 1/3 → "많이 두면 는다"의 대부분은 성향
- 1월 특징 15개로 이후 개인차의 약 18%만 예측(교차검증 R²). 대부분은 낮게 시작한 사람이 따라잡는 효과
- 주의: 레이팅 매칭 효과가 따라잡기에 섞였을 수 있음(아직 분리하지 않음)
