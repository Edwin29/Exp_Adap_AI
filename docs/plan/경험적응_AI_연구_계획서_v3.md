# 경험 적응 AI 연구 계획서 (프로젝트 지식용)

작성: Woncheol · v3 (2026-10-22: "발달"→"적응" 재정의, 가치·지각 분리, 목표 자리 추가, 사건 흐름 단위 갱신 반영)

## 1. 연구 개요

정답률이 아니라 **경험에 따라 판단이 바뀌는 인간의 적응 과정 자체**를 학습 목표로 삼는 AI를 만든다. 적응의 방향은 정하지 않는다. 향상, 정체, 흔들림, 하락 모두 재현 대상이다. 개인 프로젝트로 시작해 졸업 연구로 이어가는 것이 목표다.

**적응의 작업 정의.** 적응 = 경험이 내부 상태를 바꾸고, 그 결과 이후의 판단이 체계적으로 달라지는 것. 무작위 흔들림과 구분하는 세 조건:

1. 경험 의존성: 다른 경험이면 다르게 변한다.
2. 지속성: 변화가 금방 사라지지 않는다.
3. 설명 가능성: 변화가 상태 변화로 설명된다.

"무엇에 적응하나"(승패, 자기 예측, 주변의 기준, 자기 만족 기준)는 미리 정하지 않고 검증할 가설로 둔다. "나아짐"은 목표가 아니라, 피드백 구조와 목표 같은 조건에 따라 나오거나 안 나오는 결과로 본다.

| 구분 | 기존 AI | 이 연구 |
| --- | --- | --- |
| 목표 | 정답률, 과제 수행 능력 극대화 | 인간다운 적응 궤적 재현 (방향 무관, 사람 간 차이 포함) |
| 학습 이후 | 가중치 고정, 행동도 고정 | 가중치 고정, 내부 상태와 판단 기준은 계속 변화 |
| 평가 | 최종 성능 | 변화의 순서, 실수 유형, 전환 시점 |
| 해석 | 부차적 | 최우선 요구사항. 상태 변화를 사람이 납득할 수 있어야 함 |

- **핵심 연구 질문:** ① 가중치가 고정된 모델이 경험만으로 내부 상태를 바꿔 가며, 일반적인 인간의 분포 안에 드는 방식으로 적응할 수 있는가? ② 같은 경험에서 사람마다 향상·정체·하락이 갈리는 분포까지 재현하는가? ③ 그 변화를 사람이 이해할 수 있는 형태로 설명할 수 있는가?
- **후속 질문:** 같은 환경에서 목표만 달리 주면 적응이 어떻게 달라지는가?
- **최종 목표:** 특정 플레이어가 아니라 **일반적인 인간처럼** 경험에 적응하는 학습자. 늘기도 하고 머물기도 하는 것까지 포함한다. "일반적인 인간"은 체스 플레이어 분포의 특정 구간 안에 궤적이 속하는지로 판정한다.
- **예측과 행동의 관계:** 특정 플레이어의 미래를 예측하는 모델은 목표가 아니라, 사람 데이터로 학습자를 사전학습시키는 방법이다. 같은 모델에 자기 경험을 넣으면 행동하는 학습자가 된다.
- **한 문장 차별점:** Maia-2는 실력을 알려줘야 그 수준처럼 둔다. 이 연구의 모델은 경험을 주면 스스로 바뀐다. 사람처럼 늘기도, 머물기도, 흔들리기도 한다.
- **관련 작업과의 관계:** Self Model("사람이 되는 것") 프로젝트와는 상하위가 아니라 같은 관심 방향에서 겹치고 연결되는 별개 연구. Lobotomy Corporation 플레이 기록 프로젝트(AI 플레이 + 사고 과정 기록, Unity MCP + Codex 플러그인)는 이 연구의 계기이자 후반 도메인 후보. 로컬 모델 전환(비용 문제)은 별개 트랙.

## 2. 진행 흐름 요약

사람에게서 판단 기준 변화를 재는 자를 먼저 만들고 → 사람 대국으로 "경험에서 배우는 학습자"를 사전학습시킨 뒤 → 그 학습자에게 자기 경험을 주어 스스로 적응하게 하고 → 처음 만든 자로 사람다운지 판정한다.

| 단계 | 입력 | 하는 일 | 다음 단계에 넘기는 것 |
| --- | --- | --- | --- |
| 1. 사람 측정 | 사람의 대국 기록 | 트레이드오프 국면의 선택(가치)과 실수 유형(지각)으로 판단 변화 측정 | 측정 도구(개념 정의, 선택 모델)와 증거(사람에게 그런 변화가 있다) |
| 2. 예측 모델 | 사람의 대국 기록 (원본) | 과거 대국으로 상태를 갱신하며 이후 수 예측 | 학습된 갱신 규칙 U와 정책 π = 경험에서 배우는 학습자 |
| 3. 행동 모델 | 모델 자신의 대국 | 같은 U와 π로 직접 두고 자기 대국으로 상태 갱신 | 사람 분포 안에서 적응하는 학습자 |

주의: 예측 모델은 1단계에서 추출한 변화가 아니라 **원본 대국 기록**으로 학습한다. 1단계 측정값은 입력이 아니라 **잣대**다.

| 1단계 측정의 쓰임 | 역할 |
| --- | --- |
| 2단계 학습 | 상태의 개념 차원이 실제 그 의미를 갖도록 맞추는 기준 |
| 2단계 검증 | 모델 상태 변화가 사람에게서 측정한 변화와 일치하는지 비교 |
| 3단계 평가 | 모델이 둔 대국에 같은 측정법을 적용해 사람 분포와 비교 (같은 자로 재기) |

## 3. 용어

| 용어 | 뜻 |
| --- | --- |
| 국면 (position) | 어느 한 순간의 체스판 상태 전체: 기물 배치, 차례, 캐슬링 권리, 앙파상 칸, 50수 카운터. FEN 한 줄로 표현. 게임 단계(오프닝 등)의 의미가 아님 |
| 개념 | 판단에 쓰이는 체스 요소. 기물 가치, 킹 안전, 기동성, 폰 구조, 주도권, 단순화 성향 등 10개 내외 후보 (목록 미확정) |
| 킹 안전 | 킹이 얼마나 보호되어 있는가: 캐슬링 여부, 킹 앞 폰 방패, 킹 근처 열린 파일, 킹 주변 상대 기물 수. 계획서 전반에서 대표 **예시**로 사용 |
| "킹 안전을 더 중요하게 여기게 됨" | 킹 안전과 다른 이득이 충돌하는 상황에서 예전보다 안전 쪽을 더 자주 고르게 됨. "아는 것"과 "중요하게 여기는 것"은 다름 |
| 트레이드오프 국면 | 두 개념의 이득이 충돌하는 국면 (예: 폰을 먹으면 킹 앞 파일이 열림) |
| 드러난 선호 | 무엇을 포기하고 무엇을 고르는지로 가치를 추론하는 방식 |
| 상태 병목 | 수를 고를 때 과거 기록을 직접 보지 못하고 상태 S만 보게 하는 제한 |
| teacher forcing | 경험으로 항상 실제 사람의 대국을 넣는 학습 방식 |
| 적응 | 1장의 작업 정의. 방향 없음 |
| 가치 판단 | 알아챈 것들 중 무엇을 더 중시하나. 예: 폰을 먹을지 킹을 지킬지 |
| 지각 | 판에 있는 요소를 알아채는가. 예: 내 나이트가 노려지는 걸 보나. 기존 "능력(수읽기)"을 더 좁게 정의 |
| 목표(맥락) G | 학습자에게 밖에서 주는 조건. 무엇에서 배우고 무엇을 고를지에 영향. 1~3단계는 "없음" |
| 피드백 구조 | 판단과 결과가 얼마나 즉각적이고 분명하게 연결되나. 공짜 기물 실수는 즉각적, 캐슬링 미룸은 지연·혼잡 |
| 사건 흐름 | 관측 / 자기 행동 / 환경 반응 / 결과 신호 / 경계 / 시간 / 목표로 이뤄진 공통 틀. 도메인마다 칸 내용과 세밀도만 정함 |

킹 안전 가설: "초보는 기물 욕심을 내다 킹 공격으로 여러 번 지면서 킹 안전을 배운다"는 체스계의 통념. 검증된 사실이 아니며 1단계의 첫 확인 대상. 2026-10-22 현재, 1·2월 데이터에서 킹 공격 패배 직후의 습관 변화는 관찰되지 않았다(왕 안전 재분석 문서).

## 4. 구조

두 시간 척도로 분리하면 "고정 가중치"와 "적응 방식 학습"은 모순이 아니다. 외부 루프는 사전학습에서만 돌며 변화 규칙을 학습하고, 배포 후에는 내부 루프만 돈다.

```
[외부 루프 · 사전 메타학습]
    고정 가중치 + 가소성 규칙  ◀──── 궤적 손실 (학습 시에만) ────┐
            │ 규칙 적용                                          │
            ▼                                                    │
[내부 루프 · 배포 후, 가중치 고정]                                │
    경험 입력 (대국 1..t) → 내부 상태 갱신 (개념 차원 + 자유 차원) → 다음 대국의 행동
                                    │ 사후 분석
                                    ▼
                      해석 출력: 수치 궤적 → 원인 귀속 → 자연어 설명
```

### 학습자의 부품

| 부품 | 역할 | 가중치 |
| --- | --- | --- |
| 국면 인코더 E | 체스 국면을 표현으로 변환 | 고정 |
| 상태 S | 현재 판단 기준: 가치 차원(개념별 가중치) + 지각 차원(개념별 알아채는 정도) + 자유 차원 | 가변 |
| 갱신 규칙 U | S(t+1) = U(S(t), 사건 e(t), G) | 고정 |
| 정책 π | π(수 \| 국면, S, G) | 고정 |
| 목표 G | 밖에서 주는 맥락 | 가중치 아님(입력) |

1~3단계는 G = 없음. 목표를 바꾸는 실험은 3단계 통과 후의 후속 질문이다(9장 3.5).

U + π가 곧 학습자다. 예측 모델 = 학습자에게 남의 경험을 넣은 것, 행동 모델 = 같은 학습자에게 자기 경험을 넣은 것. 가중치는 바뀌지 않는다.

### 상태 차원의 성질 표시

개념 차원마다 도메인과 무관한 **성질**을 붙인다. 갱신 규칙 U는 개념의 내용(예: "왕")을 모르고 이 성질만 보고 움직인다. 같은 성질을 가진 차원은 U의 파라미터를 공유한다.

| 성질 | 값의 예 | 체스 예 |
| --- | --- | --- |
| 종류 | 가치 / 지각 / 자원 / 습관 | 왕 안전 = 가치, 공짜 기물 = 지각 |
| 피드백 지연·명료도 | 즉각·분명 ~ 지연·혼잡 | 공짜 기물은 다음 수에 손실, 캐슬링 미룸의 대가는 수 수 뒤 다른 원인과 섞여 옴 |
| 복잡도 | 몇 단계 앞을 봐야 보이나 | 공짜 기물 1수, 포크·핀 2수 |

새 도메인에서는 개념 목록과 각 개념의 성질만 새로 채우고 U는 그대로 옮긴다. 예: "피드백이 늦은 차원일수록 사건 하나당 조금만 바뀐다"는 규칙은 개념 내용과 무관하다. 성질 값은 처음에는 사람이 정하고(약한 가정), 이후 데이터로 추정한 값과 대조한다.

| 모드 | 경험 입력 | 행동 | 루프 |
| --- | --- | --- | --- |
| 관찰(예측) | 사람의 대국 1..t | 사람의 다음 대국 수에 확률을 매김 | 열린 루프, 정답 있음 |
| 행동 | 자기 대국 1..t | 자기 상태로 수를 생성, 결과가 다시 경험으로 | 닫힌 루프, 분포로 평가 |

### 예측 모델 설계 결정

| 설계 결정 | 내용 | 이유 |
| --- | --- | --- |
| 상태 병목 | 수를 고를 때 오직 S만 봄 | 기록 검색 지름길 차단. 없으면 S가 학습자 상태가 되지 않아 행동 모델로 전환 불가 |
| 플레이어 ID·레이팅 입력 금지 | Maia-2와 달리 실력 정보 미제공 | 실력을 알려주면 적응을 학습할 필요가 없음 |
| 사람이 볼 수 있는 신호만 | U의 입력은 수, 상대 수, 승패, 소요 시간 | 엔진 평가값은 사람이 못 보는 정보. 실수 분류 라벨로만 사용. 목표 G는 사람 데이터에서 관찰되지 않으며, 레이팅전/친선전/토너먼트 여부만 간접 맥락으로 쓸 수 있음 |
| 공통 출발 상태 S0 | 공통 초심자 상태 또는 처음 몇 판으로 추정 | 처음부터 자라는 닫힌 루프 실험 가능 |
| 사건 단위 갱신 | 갱신 단위는 사건 흐름. 도메인마다 칸 내용·세밀도만 정함. 체스 실험은 설정으로 대국 끝에서만 갱신하고, 대국 안의 수는 직전 상태로 예측 | 도메인 공통 틀 유지 + 체스에서는 경험 → 판단 변화 → 다음 대국 행동의 단위를 명확히 (2026-10-22 결정) |

내부 상태 구현 후보: 가소성 Transformer의 fast weight, Titans식 테스트 시점 메모리, 또는 조합.

### 예측에서 행동으로: 4단계 다리

| 단계 | 하는 일 | 정답 | 통과 기준 |
| --- | --- | --- | --- |
| ① teacher forcing 예측 | 사람 경험으로 S 갱신, 다음 대국 수 예측 | 있음 | 상태 없는 정적 모델보다 예측이 좋다 |
| ② 반사실 경험 테스트 | 기록에서 특정 경험(예: 킹 공격 패배 7판)을 빼거나 넣고 S 변화 관찰 | 부분적 | 경험 내용에 따라 S가 다르게 변한다 (평균 통계 지름길 배제) |
| ③ 자유 주행 예측 | 사람의 1~t판만 주고 이후는 모델이 직접 두며 자기 경험으로 S 갱신. N판 뒤 실제 그 사람과 비교 | 있음 | 실제 미래 궤적에서 크게 벗어나지 않는다 |
| ④ 완전 닫힌 루프 | S0에서 출발해 자기 경험만으로 적응 | 없음 | 평가 기준(7장)의 분포 판정 |

③이 핵심 다리다. 행동 모드인데도 정답이 남아 분포 이동을 측정할 수 있다.

- **닫힌 루프의 상대:** Maia 계열 모델을 레이팅별 상대 풀로 두고 Elo 매칭. 이기면 더 강한 상대를 만나는 경험 구조 재현.
- **④가 기대에 못 미칠 때:** 대국을 거치므로 미분 불가. 외부 루프에서 진화 전략이나 강화학습으로 U를 추가 조정. 사전학습 단계라 배포 후 가중치 고정 조건과 충돌하지 않음.

## 5. 목적함수

### 학습 순서

1. 초기 상태 S0에서 출발
2. 대국 g1의 모든 수를 S0로 예측하고 손실 계산
3. S1 = U(S0, g1)로 갱신
4. g2의 모든 수를 S1로 예측하고 손실 계산, 반복

### 개념 차원의 의미 고정

| 방법 | 내용 | 역할 |
| --- | --- | --- |
| A. 구조로 묶기 | 수의 점수 = Σ S가치 × q지각 × Δ개념(수) + 자유 부분 f(국면, S자유, 수). q지각은 그 국면에서 해당 개념의 변화를 알아챌 확률(0~1)로, 지각 차원과 국면의 난이도(예: 몇 수 앞을 봐야 보이나)에서 계산. Δ는 python-chess로 계산한 개념 변화량. 점수에 softmax | 주 방법. 1단계 선택 모델과 수식이 같아 정의상 같은 뜻. 개입 충실도도 구조적으로 성립 |
| B. 값으로 맞추기 | S개념이 1단계 추정치에 가까워지도록 손실 추가 | 보조. 추정치가 잡음이 많고 듬성듬성함 |

예시:

| | 수 A (폰 먹기) | 수 B (킹 앞 지키기) |
| --- | --- | --- |
| Δ기물 / Δ킹안전 | +1 / −2 | 0 / +1 |
| S기물 1.0, S킹 0.1 | 0.8 (선호) | 0.1 |
| S킹 0.6으로 성장 | −0.2 | 0.6 (선호) |

주의: 자유 부분이 강하면 킹 안전 정보를 흡수해 개념 부분이 비어 버림 → L자유로 억제.

주의(약한 가정, 2단계 직전에 다시 검토): 두 곱(S가치 × q지각)은 식별이 어렵다. 식별은 국면 종류에 기대한다. 평가 동등 트레이드오프 국면(둘 다 보인다고 볼 만한 곳)은 가치를, 한 수짜리 공짜 기물 국면(가치 판단이 필요 없는 곳)은 지각을 주로 알려 준다. q지각의 형태도 그때 확정한다.

### 손실 항

| 항 | 형태 | 하는 일 | 필수 여부 |
| --- | --- | --- | --- |
| L예측 | 각 대국 실제 수의 음의 로그우도 (직전 상태로 예측) | 주 손실 | 필수 |
| L정렬 | (S − 1단계 추정치)² ÷ 추정 불확실성. S가치는 선택 모델 추정치, S지각은 실수 유형별 빈도에 맞춤 | 개념 차원을 측정값에 맞춤 | 보조 |
| L자유 | 자유 부분 출력 크기 벌점 | 개념 부분이 먼저 설명하도록 강제 | 방법 A 시 필수 |
| L변화 | 대국 간 상태 변화량 L1 벌점 | 출렁임 방지, 단계 전이는 허용 | 권장 |

L = L예측 + λ1·L정렬 + λ2·L자유 + λ3·L변화

### L예측 국면 가중치

| 국면 | 가중치 |
| --- | --- |
| 강제수, 유일한 합법수 | 0 |
| 일반 국면 | 1 |
| 트레이드오프 국면 | 높게 |
| 사람이 엔진 최선수와 다르게 둔 국면 | 높게 |

실수 유형 일치는 별도 손실 대신 이 가중치로 처리. "현재와 미래 행동 차이 예측" 같은 별도 손실도 두지 않음 (매 대국을 직전 경험까지 반영한 상태로 예측하는 것 자체가 변화의 학습).

### 평가 전용 (손실에 넣지 않음)

| 항목 | 이유 |
| --- | --- |
| 반사실 경험 테스트 | 학습 목표로 쓰면 테스트가 의미를 잃음 |
| 미학습 플레이어 예측 성능 | 일반화 확인, 커브 피팅 방지 |
| 개입 충실도 | 자유 부분 누수 확인 |

난점: λ 균형이 결과를 좌우. λ2를 키우면 예측 정확도 하락, 줄이면 개념 차원이 빔. 이 트레이드오프 곡선 자체를 "해석가능성의 비용"으로 보고.

그냥 학습과의 구분: 승률 상승은 어떤 RL 에이전트에도 있다. 대상은 전략 습득 순서, 단계별 실수 유형, 정체기와 퇴행, 판단 기준의 변화.

## 6. 판단 변화 측정 방법: 가치와 지각 (사람 데이터)

"킹 안전을 중요하게 여기기 시작했다"는 관찰 불가능한 잠재 변수 → 트레이드오프 국면의 선택(드러난 선호)으로 추론. 이 측정법 정의가 첫 번째 방법론적 기여.

### 결과 지표로 재면 안 되는 이유

| 잘못된 측정 | 왜 틀리나 |
| --- | --- |
| 둔 국면의 평균 킹 안전 점수 상승 | 상대 약화, 오프닝 변경, 실력 상승일 수 있음 |
| 킹 공격 패배 비율 감소 | 가치가 아니라 지각 향상일 수 있음 |

### 절차

1. 각 국면에서 후보 수마다 개념 변화량 계산
2. 기물 이득과 킹 안전이 충돌하는 트레이드오프 국면만 추출
3. 엔진 평가로 두 수가 거의 동등한 국면만 남김 (평가 차이 0.3폰 이내, 기준값은 검증 필요)
4. 선택 모델(조건부 로짓) 적합: P(수 m) ∝ exp(w기물·Δ기물 + w킹·Δ킹안전 + …)
5. 대국 구간별 w킹 추정 후 시간 추적 (예: 1~100판 0.12 → 101~200판 0.31)

### 가치와 지각의 분리

| 국면 종류 | 안전한 수를 골랐을 때 의미 |
| --- | --- |
| 두 수가 객관적으로 동등 | 가치: 같은 값이면 안전을 택함 |
| 안전한 수가 객관적으로 더 좋음 | 지각: 위협을 알아봄 |
| 안전한 수가 객관적으로 더 나쁨 | 과잉 가치: 지나친 경계 (전환기 현상 후보) |

### 추적 요소 선정 기준

추적 요소(왕 안전 등)는 일반화의 대상이 아니라, 일반 법칙을 재고 시험하기 위한 측정 지점이다. 고르는 기준은 "체스에서 중요한가"가 아니라 **"일반 축(종류 × 피드백 × 복잡도)의 서로 다른 칸을 채우는가"**다. 그래야 "피드백이 즉각적인 판단부터 바뀐다", "쉬운 지각이 어려운 지각보다 먼저 바뀐다" 같은 도메인 무관 법칙을 체스 안에서 시험할 수 있다.

| 추적 요소 | 종류 | 피드백 | 복잡도 | 상태 |
| --- | --- | --- | --- | --- |
| 왕 안전 (캐슬링 미룸, 트레이드오프 선택) | 가치 | 지연·혼잡 | 중간 | 측정 중 |
| 공짜 기물 실수 | 지각 | 즉각 | 1수 | 측정 중 |
| 두 수짜리 전술 허용 (포크, 핀) | 지각 | 즉각 | 2수 | 분류 완료, 추적 예정 |
| 시간 사용 (수당 시간, 시간패) | 자원 | 즉각 | 낮음 | 예정 |
| 퀸 조기 출동, 전개 지연 | 습관 | 지연 | 낮음 | 예정 |

같은 축의 다른 도메인 사례(예: Lobotomy Corporation의 에너지 할당량 vs 격리 실패 위험 = 가치 축)를 대응표로 둔다.

### 지각 측정: 실수 유형

엔진으로 큰 실수(한 수에 승률 30%p 이상 손실)를 찾고, 엔진 최선수와 상대의 최선 응수로 유형을 나눈다: 옮긴 기물을 내줌, 다른 기물을 내줌, 위협 무시, 잡을 기물 놓침, 전술 허용, 메이트 허용, 기타. 한 수짜리 공짜 기물 실수는 가치 판단이 끼어들 여지가 거의 없어 지각 지표로 쓴다. 2026-10-22 분석에서 초보의 큰 실수 감소 중 약 70%가 이 유형이었다.

### 보조 표지 (초기 탐색용)

캐슬링 시점, 캐슬링한 쪽 폰 이동 횟수, 독 든 폰 거절률, 킹 노출 블런더 빈도(능력 지표).

### 교란 변수 통제

| 교란 | 통제 |
| --- | --- |
| 실력 상승 | 같은 레이팅 구간 코호트 대비 차이 |
| 오프닝 변경 | ECO 코드별로 같은 오프닝 안에서 비교 |
| 시간 제한 | 한 가지 시간 제한만 사용 |
| 상대 수준 | 상대 레이팅을 선택 모델 공변량으로 포함 |

### 경험과의 연결: 사건 연구

1. 사건 정의: 킹 공격으로 진 대국
2. 사건 전후 20판의 w킹 비교
3. 대조군: 다른 이유(기물 손실, 시간 패)로 진 직후의 w킹 변화
4. 킹 공격 패배 뒤에만 w킹이 유의하게 오르면 "그 경험이 판단 기준을 바꿨다"는 근거
5. "무엇에 적응하나"를 가르는 비교: 예상 밖의 패배(상대 레이팅이 낮을 때) 뒤 변화가 더 크면 예측 오차 가설, 목표 레이팅 근처에서 변화가 멈추면 만족화 가설, 레이팅대 표준 쪽으로 끌리면 사회적 기준 가설을 지지한다.

피드백이 즉각적인 판단(공짜 기물)과 지연되는 판단(캐슬링)을 나눠 비교한다.

모델의 반사실 경험 테스트를 사람 데이터에서 먼저 해보는 것. 사람에게서 효과가 안 보이면 모델에게 요구할 근거도 없다.

### 한계

- 트레이드오프이면서 평가가 동등한 국면은 드물다. 구간당 표본이 수십 개일 수 있어 표본 수부터 확인.
- 현대 Stockfish(NNUE)는 개념별 점수를 주지 않는다. 폰 실드, 킹 주변 열린 파일, 킹 구역 공격자 수 등 휴리스틱을 python-chess로 직접 구현. 정의가 결과를 좌우.

## 7. 평가 기준: 일반적인 인간의 정의

"일반적인 인간" = 체스 플레이어 분포의 특정 구간 안. 단 한 시점이 아니라 **궤적 전체**가 구간 안에 있어야 하고, **여러 실행의 퍼짐**도 사람 집단의 퍼짐과 비슷해야 한다.

| 층위 | 지표 | 판정 |
| --- | --- | --- |
| 개별 궤적 | 같은 시작 레이팅·같은 판 수 코호트 대비 레이팅 궤적 | 백분위 구간(예: 10~90%) 안 |
| 가치·지각 | 개념 가중치 궤적과 실수 유형 빈도 궤적 vs 사람 궤적 | 같은 구간 판정 |
| 실수 | 단계별 실수 유형 분포 | 그 실력대 사람과 일치 |
| 판별 테스트 | 사람·모델 궤적 구분 분류기 | 정확도 50%에 가까울수록 사람다움 |
| 집단 퍼짐 | 다른 시드·S0로 여러 번 돌린 결과의 분산 | 사람 집단 분산과 비슷 |
| 변화 방향의 분포 | 같은 시작점 코호트에서 향상·정체·하락 비율 | 사람 비율과 비슷 (참고: 2026-10-22 기존 유저 한 달 레이팅 변화 ±50점 안 50%, 50점 넘게 하락 24%) |
| 피드백 구조별 차이 | 즉각적 피드백 판단과 지연 피드백 판단의 변화 속도 차이 | 사람과 같은 방향·크기 |

개념 가중치 궤적은 6장의 선택 모델로 사람과 모델 모두에서 같은 방식으로 추출한다.

어느 층위도 "더 나아졌는가"를 묻지 않는다. 사람의 분포와 같은가만 묻는다.

## 8. 해석가능성 설계

해석 대상은 상태가 아니라 **상태의 변화**.

| 상태 구성 | 내용 |
| --- | --- |
| 개념 차원 (k개) | 판단 기준 = 개념별 가중치 |
| 자유 차원 (m개) | 개념으로 설명되지 않는 나머지 |

| 보고 지표 | 질문 |
| --- | --- |
| 개념 설명률 | 행동 변화 중 몇 %가 개념 차원 변화로 설명되는가 |
| 개입 충실도 | 개념 차원을 바꾸면 행동이 그 방향으로 바뀌는가 |
| 성능 비용 | 병목 없는 모델 대비 예측 정확도 손실 |

| 출력 층위 | 예시 |
| --- | --- |
| 수치 | 킹 안전 가중치 0.12 → 0.31 |
| 원인 귀속 | 변화량 대부분이 킹 공격으로 진 7판에서 발생 |
| 자연어 | "킹이 공격당해 여러 번 진 뒤로 수비를 우선하기 시작했어요" (위 두 층에만 근거) |

응용 예: 사용자 기보를 넣으면 현재 단계와 다음에 바뀔 판단 기준을 알려주는 코칭 도구.

## 9. 도메인 확장과 단계 계획

확장 단계는 장르가 아니라 각 단계에서 검증하는 주장으로 나눈다. 다른 게임으로 옮겨가는 것은 게임 지식이 아니라 고정 가중치에 담긴 **적응 규칙**이다. 도메인마다 가치와 지각의 비중은 다를 수 있으며(체스는 지각 비중이 큼), 이 비중 차이 자체가 검증할 가설이다.

| 단계 | 도메인 | 검증하는 주장 | 필요 조건 |
| --- | --- | --- | --- |
| 1 | 체스 | 사람 데이터로 사전학습한 학습자가 자기 경험만으로 사람 분포 안에서 적응 (변화 방향의 분포 포함) | Lichess 종단 데이터, Maia 상대 풀 |
| 2 | 다른 턴제 보드게임 | 체스에서 메타학습한 적응 규칙이 새 게임에서도 인간다운 궤적을 만듦 | 개인 단위 공개 기록 |
| 3 | 실시간 게임 | 시간 압박·불완전 정보에서도 성립 | 플레이어 ID가 붙은 리플레이 |
| 4 | Lobotomy Corporation 등 | 검증된 학습자가 복잡한 상호작용 환경에서도 사람답게 적응 | 보유한 MCP 제어·기록 인프라. 목표 G를 직접 줄 수 있어 목표 조건 실험이 가능한 도메인 |

옮겨 가는 것은 U와 "성질 → 갱신 방식" 규칙이며, 개념 목록과 성질 값은 도메인마다 새로 채운다(4장 성질 표시). 도메인 간 축 대응표는 사람이 만든다(약한 가정, 11장).

행동 모델로의 전환은 체스 안에서 완료한다.

| 순서 | 내용 | 다음으로 가는 기준 |
| --- | --- | --- |
| 1 (현재) | 체스 · 기초와 사람 데이터 측정 | 사람에게서 적응의 세 조건(경험 의존성·지속성·설명 가능성)을 측정할 수 있다. 가치와 지각 중 하나 이상에서 경험 효과가 관찰된다 |
| 2 | 체스 · 예측 모델 (① teacher forcing, ② 반사실 테스트) | 정적 모델보다 예측이 낫고 반사실 테스트 통과 |
| 3 | 체스 · 행동 모델 전환 (③ 자유 주행, ④ 닫힌 루프) | 궤적이 분포 구간 안, 판별 정확도 50% 근접 |
| 3.5 | 체스 · 목표 조건 실험 (선택) | G를 바꿔 같은 환경에서 적응 비교. 다음 단계의 조건이 아님 |
| 4 | 새 도메인 전이 | 졸업 연구 |

일정은 측정 결과에 따라 크게 달라지므로 기간보다 순서와 기준으로 관리한다.

## 12. 현재 할 일과 미결정 사항

목표: 모델 없이 **사람 데이터에서 가치와 지각의 변화, 그리고 변화 방향의 분포를 측정할 수 있는지** 확인. 개념 하나(킹 안전)로 측정법 전체를 끝까지 돌려본다.

### 기초 읽기 순서

| 순서 | 자료 | 목적 |
| --- | --- | --- |
| 1 | Maia-2 | 인간 수 예측 기준선, Lichess 데이터 처리 |
| 2 | AlphaZero 체스 지식 습득 | 개념 라벨링과 탐침 |
| 3 | 이산 선택 모델(조건부 로짓) 기초 | 드러난 선호 측정의 통계 기반 |
| 4 | Concept Bottleneck Models + 비판 논문 | 해석 가능한 상태 설계와 한계 |
| 5 | 가소성 Transformer, Titans | 내부 상태 구현 (2단계 직전) |

### 작업

- [ ] Lichess DB 한 달치 다운로드, 시간 제한 한 가지로 고정, 500판 이상 플레이어 추출
- [ ] python-chess로 킹 안전 휴리스틱 구현 (폰 실드, 킹 주변 열린 파일, 킹 구역 공격자 수)
- [ ] Stockfish로 후보 수 평가, 트레이드오프·평가 동등 국면 추출 후 플레이어당 표본 수 확인
- [ ] 보조 표지 플레이어별 궤적 시각화
- [ ] 조건부 로짓으로 구간별 w킹 추정, 같은 레이팅 코호트와 비교
- [ ] 킹 공격 패배 사건 연구 시범

### 미결정 사항

- 내부 상태 구현: fast weight vs Titans식 메모리 vs 조합
- 개념 차원 목록 (10개 내외 선정 기준)
- 공통 출발 상태 S0 방식
- 시간 제한 (블리츠 vs 래피드)
- 평가 동등 기준값 (0.3폰 적절성)
- λ1~λ3 설정 방식
- 적응의 동력 가설: 승패, 예측 오차, 만족화, 사회적 기준. 택1이 아니라 데이터로 가른다(6장 사건 연구 5). 피아제의 동화/조절은 해석 틀로 유지
- 목표 G의 구현 방식: U에만, π에만, 둘 다
- q지각의 형태 (5장, 2단계 직전 검토)
- 2단계 도메인 후보
