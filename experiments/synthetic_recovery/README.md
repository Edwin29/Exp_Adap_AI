# 가짜 사람 데이터로 갱신 규칙 복원 실험

질문: 다음 수 예측 손실만으로 학습해도, 갱신 규칙 U가 "경험 → 가치 변화" 규칙을 배우는가.

## 0단계: 시뮬레이터 (`simulate.py`, 제공됨)

```
python simulate.py                                   # data/sim_default.npz (+ .json 요약)
python simulate.py --positions 2 --out data/sim_p2.npz   # 신호 약하게
python simulate.py --drift_sd 0.02 --out data/sim_drift.npz  # 사건과 무관한 흔들림 추가
```

numpy만 필요. 기본 설정(1,000명 × 300판 × 8국면 × 3후보) 생성에 약 5초, 파일 약 54MB.

### 파일 내용

| 키 | 모양 | 모델 입력? | 뜻 |
|---|---|---|---|
| `feats` | [N, G, P, C, 2] | 예 | 후보 수 특성. `[...,0]` 킹 안전, `[...,1]` 기물 |
| `choices` | [N, G, P] | 예 (예측 대상) | 고른 후보 번호 |
| `outcome` | [N, G] | 예 (사건) | 0 승, 1 무, 2 킹 공격 패배, 3 다른 패배 |
| `split` | [N] | 분할용 | 0 학습, 1 검증, 2 시험 (사람 단위) |
| `w_king` | [N, G] | **아니오** | 그 판을 두는 동안의 참값 킹 안전 가치 |
| `alpha`, `target`, `w0`, `static` | [N] | **아니오** | 사람별 참값 갱신 파라미터 |

참값(`w_king`, `alpha`, ...)은 3단계 복원 검사에만 쓴다. 모델 입력에 넣으면 실험이 무의미해진다.

### 참값 규칙

- 선택: p(c) ∝ exp(w_king·f_king(c) + 1.0·f_mat(c))
- 갱신: 킹 공격 패배 직후에만 w_king ← w_king + α(target − w_king). 약 20%는 α = 0.
- 닫힌 고리: 고른 수의 킹 특성 평균이 낮을수록 킹 공격 패배 확률 증가.
- 시점 규칙: g판의 선택은 `w_king[:, g]`로 만들어지고, g판 결과로 갱신된 값이 g+1판에 쓰인다.
  따라서 모델의 S도 g판 결과는 g+1판 예측부터 반영해야 한다(같은 판 결과를 미리 보면 누수).
